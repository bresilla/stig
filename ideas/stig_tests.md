# Stig Test Suite - Design Document

## Overview

Create a documentation-driven testing system for C++ that integrates with Stig. The system consists of:

1. **`stig_test.h`** - A generated header file with test macros
2. **`stig init --test`** - Command to initialize test infrastructure
3. **`stig test`** - Command to discover, compile, and run tests

## Goals

- Tests are linked to documented functions via `@test` tag
- Simple, doctest-like API
- Header is generated by stig (not static)
- Test binary communicates with stig for reporting

---

## Architecture

### 1. `stig init` Command

Creates project scaffolding:

```bash
stig init
# Creates:
#   ./stig.toml          - Configuration file
#   ./test/              - Test directory
#   ./test/stig_test.h   - Generated test header
#   ./test/main.cpp      - Test runner main file
```

### 2. Generated `stig_test.h`

The header provides:

```cpp
// Auto-generated by stig - do not edit manually
#ifndef STIG_TEST_H
#define STIG_TEST_H

#include <iostream>
#include <vector>
#include <string>
#include <functional>
#include <cstring>

namespace stig {
namespace test {

// Test registration
struct TestCase {
    const char* name;
    const char* file;
    int line;
    std::function<void()> func;
};

inline std::vector<TestCase>& registry() {
    static std::vector<TestCase> tests;
    return tests;
}

struct TestRegistrar {
    TestRegistrar(const char* name, const char* file, int line, std::function<void()> func) {
        registry().push_back({name, file, line, func});
    }
};

// Assertion tracking
struct Context {
    int assertions = 0;
    int failures = 0;
    const char* current_test = nullptr;
    const char* current_file = nullptr;
    int current_line = 0;
};

inline Context& ctx() {
    static Context c;
    return c;
}

// Output format (for stig integration)
inline void report_failure(const char* expr, const char* file, int line) {
    std::cerr << file << ":" << line << ": FAILED: " << expr << "\n";
    ctx().failures++;
}

inline void report_success() {
    ctx().assertions++;
}

// Main runner
inline int run_all() {
    int failed = 0;
    for (auto& tc : registry()) {
        ctx().current_test = tc.name;
        ctx().current_file = tc.file;
        ctx().current_line = tc.line;
        ctx().assertions = 0;
        ctx().failures = 0;
        
        std::cout << "Running: " << tc.name << "\n";
        
        try {
            tc.func();
        } catch (const std::exception& e) {
            std::cerr << tc.file << ":" << tc.line << ": EXCEPTION: " << e.what() << "\n";
            ctx().failures++;
        } catch (...) {
            std::cerr << tc.file << ":" << tc.line << ": UNKNOWN EXCEPTION\n";
            ctx().failures++;
        }
        
        if (ctx().failures > 0) {
            failed++;
            std::cout << "  FAILED (" << ctx().failures << " failures)\n";
        } else {
            std::cout << "  PASSED (" << ctx().assertions << " assertions)\n";
        }
    }
    
    std::cout << "\n";
    std::cout << "Total: " << registry().size() << " tests, " << failed << " failed\n";
    
    return failed > 0 ? 1 : 0;
}

} // namespace test
} // namespace stig

// ============================================================================
// MACROS
// ============================================================================

#define STIG_TEST(name) \
    static void stig_test_##name(); \
    static stig::test::TestRegistrar stig_reg_##name(#name, __FILE__, __LINE__, stig_test_##name); \
    static void stig_test_##name()

#define STIG_CHECK(expr) \
    do { \
        if (!(expr)) { \
            stig::test::report_failure(#expr, __FILE__, __LINE__); \
        } else { \
            stig::test::report_success(); \
        } \
    } while(0)

#define STIG_REQUIRE(expr) \
    do { \
        if (!(expr)) { \
            stig::test::report_failure(#expr, __FILE__, __LINE__); \
            return; \
        } else { \
            stig::test::report_success(); \
        } \
    } while(0)

#define STIG_CHECK_EQ(a, b) STIG_CHECK((a) == (b))
#define STIG_CHECK_NE(a, b) STIG_CHECK((a) != (b))
#define STIG_CHECK_LT(a, b) STIG_CHECK((a) < (b))
#define STIG_CHECK_LE(a, b) STIG_CHECK((a) <= (b))
#define STIG_CHECK_GT(a, b) STIG_CHECK((a) > (b))
#define STIG_CHECK_GE(a, b) STIG_CHECK((a) >= (b))

#define STIG_REQUIRE_EQ(a, b) STIG_REQUIRE((a) == (b))
#define STIG_REQUIRE_NE(a, b) STIG_REQUIRE((a) != (b))

// For exception testing
#define STIG_CHECK_THROWS(expr) \
    do { \
        bool threw = false; \
        try { expr; } catch (...) { threw = true; } \
        if (!threw) { \
            stig::test::report_failure(#expr " should throw", __FILE__, __LINE__); \
        } else { \
            stig::test::report_success(); \
        } \
    } while(0)

#define STIG_CHECK_NOTHROW(expr) \
    do { \
        bool threw = false; \
        try { expr; } catch (...) { threw = true; } \
        if (threw) { \
            stig::test::report_failure(#expr " should not throw", __FILE__, __LINE__); \
        } else { \
            stig::test::report_success(); \
        } \
    } while(0)

#endif // STIG_TEST_H
```

### 3. Generated `test/main.cpp`

```cpp
// Auto-generated by stig - do not edit manually
#define STIG_TEST_MAIN
#include "stig_test.h"

int main(int argc, char** argv) {
    // TODO: Parse arguments for filtering, output format, etc.
    return stig::test::run_all();
}
```

### 4. Example Test File

```cpp
// test/test_math.cpp
#include "stig_test.h"
#include "math.hpp"  // Your library header

STIG_TEST(test_factorial_basic) {
    STIG_CHECK_EQ(factorial(0), 1);
    STIG_CHECK_EQ(factorial(1), 1);
    STIG_CHECK_EQ(factorial(5), 120);
}

STIG_TEST(test_factorial_negative) {
    STIG_CHECK_THROWS(factorial(-1));
}

STIG_TEST(test_add) {
    STIG_CHECK_EQ(add(2, 3), 5);
    STIG_CHECK_EQ(add(-1, 1), 0);
}
```

### 5. Documentation Integration

In your header file:

```cpp
/**
 * @brief Calculates factorial
 * @param n Input (must be >= 0)
 * @return n!
 * @test test_factorial_basic
 * @test test_factorial_negative
 */
int factorial(int n);
```

## `stig test` Command

### Usage

```bash
# Run all tests (compile + execute)
stig test

# Run specific test
stig test --filter "factorial*"

# Run tests for a specific function
stig test --for factorial

# Just list discovered tests
stig test --list

# Verify @test references exist
stig test --verify

# Output formats
stig test --format json
stig test --format junit
```

### Implementation Options

#### Option A: Stig compiles tests directly

Stig uses the system compiler to build and run tests:

```bash
stig test test/*.cpp
# 1. Stig finds all STIG_TEST macros
# 2. Generates a temporary main.cpp if needed
# 3. Compiles with g++/clang++
# 4. Runs the binary
# 5. Parses output and reports
```

#### Option B: User compiles, stig runs

User builds test binary with their build system, stig just runs it:

```bash
# User builds
cmake --build build --target tests

# Stig runs and parses output
stig test ./build/tests --format json
```

#### Option C: Hybrid (Recommended)

- `stig test` with source files → compiles and runs
- `stig test` with binary → just runs
- `stig test --verify` → checks @test references without running

## Configuration (stig.toml)

```toml
[test]
# Directory containing test files
dir = "test"

# Compiler to use
compiler = "g++"

# Compiler flags
flags = ["-std=c++17", "-Wall", "-Wextra"]

# Include paths
include_paths = ["include/"]

# Link libraries
libraries = []

# Test file pattern
pattern = "test_*.cpp"

# Output format: console, json, junit
format = "console"
```

## Integration with Documentation

### `stig check --verify-tests`

Verifies that all `@test` references point to existing tests:

```bash
stig check --verify-tests include/*.hpp

# Output:
# math.hpp:15: @test test_factorial_basic - FOUND in test/test_math.cpp:5
# math.hpp:16: @test test_factorial_negative - FOUND in test/test_math.cpp:12
# math.hpp:25: @test test_missing - NOT FOUND
```

### Documentation Output

When generating docs, show test status:

```markdown
## factorial

Calculates factorial.

**Tests:**
- ✅ `test_factorial_basic` ([test_math.cpp:5](test/test_math.cpp#L5))
- ✅ `test_factorial_negative` ([test_math.cpp:12](test/test_math.cpp#L12))
```

## Implementation Plan

### Phase 1: Basic Infrastructure
1. Add `stig init` command
2. Generate `stig_test.h` header
3. Generate `test/main.cpp`
4. Generate `stig.toml` with test config

### Phase 2: Test Discovery
1. Parse test files for `STIG_TEST` macros
2. Build test registry
3. Match against `@test` references in docs

### Phase 3: Test Execution
1. Compile tests with system compiler
2. Run test binary
3. Parse output (console/JSON)
4. Report results

### Phase 4: Integration
1. `stig check --verify-tests`
2. Show test status in generated docs
3. CI/CD integration (JUnit output)

## Open Questions

1. **Compilation**: Should stig compile tests itself or rely on user's build system?
   - Pro compile: Simpler for users
   - Pro external: More flexible, works with existing projects

2. **Header generation**: When should header be regenerated?
   - On every `stig test`?
   - Only on `stig init --test`?
   - When config changes?

3. **Test discovery**: Parse source files or run binary with `--list`?
   - Parse: Works without compiling
   - Binary: More accurate, handles templates

4. **Scope**: Start minimal or full-featured?
   - Minimal: Just STIG_TEST + STIG_CHECK
   - Full: Subcases, fixtures, parameterized tests
